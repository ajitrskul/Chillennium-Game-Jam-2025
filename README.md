# Chillennium-Game-Jam-2025
Our reposity for the Chillenium Game Jam 2025 in February with the theme "In Plain Sight". This game jam lasted between February 7th 2025 at 6:30 PM to February 9th 2025 at 1:00 PM.

## Link
The itch.io page for our game can be found at: https://avoormolen.itch.io/pixieslabyrinth
